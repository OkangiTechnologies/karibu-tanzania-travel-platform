Planning basics

  • Best season Jun–Oct and Dec–Feb driest, best for both beach and safari game viewing; Mar–May low season, lowest prices.
  • Entry Visa on arrival or e-visa for most nationalities; yellow fever certificate if arriving from an at-risk country.
  • Currency TZS nationwide; USD (2009+ notes) accepted for hotels, parks, tours.
  • Getting there Fly into ZNZ (Zanzibar) or JRO (Kilimanjaro, for the safari circuit); a domestic flight links the two in about 1–1.5h.
  • Getting around Zanzibar: dala-dala, taxis or a hired driver. Mainland parks: guided 4x4 safari vehicle, arranged through your operator.
  • Local custom Zanzibar's coast is predominantly Muslim — modest dress appreciated outside resorts, especially Stone Town.

Security & compliance

Design commitments for production

Data protection

  • TLS 1.3 in transit; AES-256 at rest
  • PII minimisation — no data retained beyond session unless booking requires it
  • Aligned with Tanzania's PDPA and GDPR principles

Access control

  • Role-based access for the operator console
  • Scoped API keys per integration partner
  • Full audit log of data & admin actions

Platform resilience

  • Rate limiting & abuse detection at the gateway
  • Graceful degradation — safe failure, clear retry message
  • Automated backups with point-in-time recovery

Model governance

  • Concierge scoped to Tanzania travel topics only
  • Forecasting & recommendation models versioned and evaluated before rollout
  • Human-in-the-loop review for low-confidence responses
